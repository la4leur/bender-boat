# Bender Boat Solution

**Developer:** Ops Normal AI LLC
**Client:** Standing Tide — 3 SANSU Bender Class vessels

## Structure

- `demo/` — HATCHLING interactive prototype (React + TypeScript)
- `docs/` — Architecture, schema, and planning documents

## Demo

The HATCHLING demo is a 7-tab interactive prototype covering:
1. Vessel Dashboard
2. Crew Roster
3. Voyage Planner
4. Watch Board
5. Crew Change Workflow
6. Change & Expense Portal
7. Travel Planner (Search, Ground Logistics, Travel Packets, Visa Tracker)
